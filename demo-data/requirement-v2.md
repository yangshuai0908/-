# 用户中心 · 账号与登录模块需求说明

版本：v1.1
状态：待评审

## 1 背景与范围

本模块承载 C 端用户的账号注册、登录、密码找回，以及管理端对账号的管理能力。本期不含微信/支付宝三方登录。

## 2 账号体系

### 2.1 账号规则

- 账号长度 8-20 位，仅允许字母、数字和下划线。
- 账号全局唯一，校验时不区分大小写。
- 密码长度 8-32 位，必须同时包含大写字母、小写字母和数字。
- 注册时需绑定手机号，手机号需短信验证通过。

### 2.2 账号状态

账号共有三种状态：

- 正常：可正常登录与使用。
- 锁定：连续登录失败触发，锁定期间不可登录。
- 停用：由管理员设置，停用账号不可登录。

状态流转：正常 ↔ 锁定（自动解锁回到正常），正常 → 停用（管理员操作），停用 → 正常（管理员操作）。

## 3 登录

### 3.1 账号密码登录

- 支持使用账号或绑定的手机号登录。
- 登录成功后跳转至用户中心首页。
- 连续输错 5 次，账号锁定 30 分钟。
- 锁定期间尝试登录，接口返回错误码 1003。
- 登录成功后失败次数清零。

### 3.2 短信验证码登录

- 用户输入手机号，获取 6 位数字验证码。
- 验证码有效期 5 分钟，超时失效。
- 同一手机号 60 秒内只能发送一次验证码。
- 同一手机号单日最多发送 10 次验证码，超出后当日不再发送。
- 验证码验证成功后立即作废，不可重复使用。

### 3.3 会话

- 登录成功后签发 token，前端在后续请求的 Authorization 头中携带。
- token 有效期为 15 分钟，超时需重新登录。
- token 失效后需重新登录。

### 3.4 图形验证码

- 同一账号连续输错 3 次密码后，后续登录必须输入图形验证码。
- 图形验证码为 4 位字符，不区分大小写，有效期 2 分钟。
- 图形验证码校验失败不计入密码失败次数，但刷新验证码重新计数。
- 登录成功后图形验证码要求解除。

## 4 密码找回

### 4.1 找回流程

- 用户通过绑定的手机号接收验证码。
- 验证码校验通过后进入设置新密码页面。
- 新密码需符合密码规则。
- 重置成功后，该账号所有已签发的 token 立即失效。

## 5 账号管理（管理端）

### 5.1 用户列表

- 支持按账号、手机号、账号状态筛选。
- 列表分页，每页默认 10 条，可选每页 20 条、50 条、100 条。
- 列表中不展示密码信息。

### 5.2 账号状态变更

- 管理员可将账号置为停用，需填写停用原因。
- 停用后该账号所有已签发的 token 立即失效。
- 管理员可将停用账号恢复为正常状态。

## 6 权限规则

- 未登录用户：仅可访问登录接口和密码找回接口。
- 普通用户：仅可查看和修改自己的账号信息。
- 客服：可查看用户基本信息，不可修改任何账号数据。
- 管理员：可查看用户列表、修改账号状态，不可查看密码明文。
- 超级管理员：在管理员权限基础上，可导出用户列表；导出需二次确认，并记录操作日志。

## 7 接口定义

```
POST   /api/auth/login
POST   /api/auth/sms/send
POST   /api/auth/sms/login
POST   /api/auth/password/reset
GET    /api/admin/users
PATCH  /api/admin/users/{userId}/status
GET    /api/admin/users/export
```

### 7.1 登录接口

POST /api/auth/login

请求体：

```json
{
  "account": "string，账号或手机号",
  "password": "string",
  "captcha": "string，图形验证码，触发风控时必填"
}
```

成功响应 200：

```json
{
  "token": "string",
  "expiresIn": "number，单位秒",
  "riskLevel": "string，风险等级：normal | captcha"
}
```

错误码：

- 1001：账号或密码错误
- 1002：账号已停用
- 1003：账号已锁定
- 1004：图形验证码错误或已过期

### 7.2 发送短信验证码

POST /api/auth/sms/send

请求体：

```json
{
  "phone": "string，11 位手机号"
}
```

成功响应 200：`{ "sent": true }`

错误码：

- 2001：手机号格式错误
- 2002：发送过于频繁，请 60 秒后重试
- 2003：当日发送次数已达上限

### 7.3 用户列表

GET /api/admin/users?keyword=&status=&page=1&pageSize=20

成功响应 200：

```json
{
  "total": "number",
  "list": [
    {
      "userId": "string",
      "account": "string",
      "phone": "string",
      "status": "normal | locked | disabled",
      "createdAt": "string"
    }
  ]
}
```

## 8 非功能要求

- 登录接口响应时间 P95 小于 500 毫秒。
- 密码不得以明文形式存储，需加盐哈希后落库。
- 所有接口需校验登录态，白名单接口除外。
